## 👩‍💻 About Me

Hi, I'm **Gursimran Kaur** 👋, A Data Analyst who loves turning messy, raw data into stories that people can act on.

My work covers the full analytics workflow:

- 🧹 **Clean** and query data in SQL
- 🔍 **Explore** and model it in Python
- 📈 **Present** the findings through interactive dashboards

This repository holds the code for my **portfolio website**, where each project card links to its own repo or live dashboard.

### 📞 [Customer Churn Prediction](https://github.com/Gur1110/Customer-Churn-Analysis)
> *"Know who's leaving before they go."*

An end-to-end data science project to predict and reduce telecom churn. Data is extracted and staged in SQL, a machine learning model in Python flags at-risk customers and uncovers key churn drivers, and the findings are delivered in an interactive Power BI dashboard.

### 🕷️ [Wikipedia Web Scraper](https://github.com/Gur1110/Wiki-Web-Scraper)
> Wikipedia revenue table → clean DataFrame

A Python scraper that sends a proper User-Agent request to Wikipedia, parses the revenue table with BeautifulSoup, and builds a clean DataFrame with rank, industry, revenue, growth, employees, and headquarters.
